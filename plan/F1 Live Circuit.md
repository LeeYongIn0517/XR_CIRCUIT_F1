# F1 Live Circuit 상세 기획서

## 1. 제품 목표
- F1 레이스 진행 중, XR 공간에서 모나코 트랙과 차량 이동을 **실시간 가시화**한다.
- 사용자에게 "현재 누가 어디서 얼마나 빠르게 달리는지"를 직관적으로 전달한다.

## 2. 화면 요구사항 상세

### 2.1 모나코 트랙 XR 오브젝트
- 기준 크기:
  - 가로 1m
  - 세로는 실제 모나코 트랙 비율 기반 스케일
  - 높이 5cm(베이스 플레이트 포함)
- 표현 방식:
  - 트랙 라인 + 노면 + 커브 구간(색 강조)
  - 스타트/피니시 라인 표시
  - 섹터 구분(선택)

### 2.2 차량 표현
- 차량 수: 20~22대 동시 표시(시즌/세션 상황 반영)
- 시각 요소:
  - 팀 컬러를 적용한 원형 마커
  - 차량 번호 또는 드라이버 약어(선택 토글)
  - 속도 기반 후광/꼬리 이펙트(선택)
- 갱신:
  - 위치 갱신 + 부드러운 보간 이동
  - 속도/순위 보조 라벨은 저빈도 갱신 가능

### 2.3 정보 패널(보조 UI)
- 현재 세션명/랩 진행 상태
- 상위 3명 요약(드라이버, 랩타임 갭)
- 날씨(트랙 온도, 기온, 강우 여부)

## 3. 트랙 에셋 제작 및 적용 전략

## 3.1 에셋 제작 도구 후보
- **Blender**: 트랙 메시 모델링, UV, 경량화(권장 기본 도구)
- **Spline/Gravity Sketch(선택)**: 빠른 초기 형태 시안 제작
- **Substance 3D Painter(선택)**: 텍스처 고급화 시 사용

### 3.2 권장 파이프라인
1. 트랙 기준 데이터 수집:
   - 모나코 트랙 2D 레이아웃(공개 지도/벡터) 확보
2. Blender에서 제작:
   - 커브 기반 트랙 경로 생성
   - 너비/높이 적용, 베이스 메시 생성
   - 폴리곤 수 최적화(모바일 XR 고려)
3. 텍스처링:
   - 경량 PBR 텍스처(저해상도 우선)
4. 내보내기:
   - `glTF/GLB` 우선
5. Android XR 적용:
   - 엔진/렌더러에서 `GLB` 로드
   - 실제 공간 스케일(1m 기준) 맞춤

### 3.3 좌표계 매핑 규칙
- OpenF1 위치 데이터를 트랙 로컬 좌표계로 정규화한다.
- 기준점:
  - 트랙 시작점(0,0)
  - 진행 방향(시계/반시계)
- 변환:
  - API 좌표 -> 정규화(0~1) -> XR 월드 좌표(미터 단위)

## 4. OpenF1 API 조사 및 사용 계획

## 4.1 핵심 사용 API
- `meetings`
  - 대회/라운드 식별
- `sessions`
  - 현재 진행 세션 식별(Practice/Qualifying/Race)
- `drivers`
  - 드라이버 번호, 이름, 약어, 팀 정보
- `location`
  - 차량 위치 좌표(트랙 내 실시간 위치 핵심)
- `car_data`
  - 속도, 기어, 스로틀, 브레이크 등 텔레메트리
- `position`
  - 순위/격차(리더보드 보조 정보)
- `intervals` (선택)
  - 드라이버 간 시간 간격 보강
- `weather` (선택)
  - 트랙/기상 상태 표시

## 4.2 API 결합 목적
- 위치 표현: `location` 중심
- 속도/동작 표현: `car_data` 결합
- 순위 및 경기 맥락: `position` + `intervals`
- 세션 문맥: `meetings` + `sessions`
- 라벨/팀컬러 매핑: `drivers`

## 4.3 폴링/동기화 권장
- 위치 데이터(`location`): 1~2초 주기
- 텔레메트리(`car_data`): 1초 주기
- 순위/격차(`position`, `intervals`): 2~4초 주기
- 기상(`weather`): 10~30초 주기
- 렌더 루프는 고주기, 네트워크 폴링은 저주기로 분리

## 5. 데이터 정확도와 UX 보정
- 네트워크 지연 시 차량 점프 방지:
  - 선형 보간 + 짧은 예측 이동 적용
- 누락 데이터 처리:
  - 최신 유효 좌표 유지
  - 일정 시간 초과 시 반투명 처리(신호 약함)
- 대량 갱신 안정화:
  - 한번에 20대 이상 업데이트 시 배치 처리

## 6. 비기능 요구사항
- 렌더 성능:
  - XR 목표 프레임 안정 유지(기기 성능별 품질 레벨)
- 안정성:
  - API 실패 시 자동 복구
- 확장성:
  - 모나코 외 타 서킷 쉽게 추가 가능한 구조

## 7. 범위 정의

### MVP 포함
- 모나코 트랙 3D 오브젝트
- 20~22대 차량 실시간 위치/속도 반영
- 기본 팀 컬러 및 간단한 정보 패널

### MVP 제외(후속)
- 고급 이펙트(잔상, 고급 셰이더)
- 리플레이/타임머신 모드
- 사용자 커스텀 카메라 프리셋 다중 저장
