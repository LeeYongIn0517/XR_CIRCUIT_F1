# F1 Live Circuit 개발 플랜

## 개발 원칙
- 문서 기준 범위: `F1 Live Circuit.md`의 MVP 우선.
- 아키텍처: Hilt 기반 Data-Domain-Presentation 3계층 고정.
- 구현 순서: 데이터 신뢰성 -> 좌표 변환 정확성 -> XR 렌더 고도화.

## Phase 0. 킥오프/설계 고정 (0.5~1일)
- 산출물:
  - 요구사항 확정본
  - 도메인 용어집(세션, 위치, 속도, 순위 등)
  - API 필드 매핑 표(OpenF1 DTO -> Domain)
- 체크포인트:
  - OpenF1 endpoint/파라미터/업데이트 주기 확정
  - 모나코 트랙 스케일 규칙 확정(가로 1m 기준)

## Phase 1. 프로젝트 베이스라인 구축 (1일)
- 작업:
  - 모듈/패키지 구조 확정(Data, Domain, Presentation)
  - Hilt DI 골격 작성(네트워크, 리포지토리, 유스케이스)
  - 공통 결과 타입(성공/실패/로딩) 규약 정의
- 완료 기준:
  - 계층 간 의존 방향 검증 완료
  - 기본 의존성 그래프 문서화 완료

## Phase 2. OpenF1 데이터 계층 구현 (2~3일)
- 작업:
  - `meetings`, `sessions`, `drivers` 연동(세션 문맥 확보)
  - `location`, `car_data`, `position` 연동(실시간 핵심)
  - 선택 API `intervals`, `weather` 추가
  - 폴링 스케줄러 및 재시도/백오프 정책 적용
- 완료 기준:
  - 세션 기준으로 20대 이상 차량 데이터 안정 수신
  - API 장애 시 자동 복구 동작 확인

## Phase 3. Domain 유스케이스/좌표 변환 (1.5~2일)
- 작업:
  - 실시간 스트림 병합 유스케이스 구현
  - 위치/속도/순위 통합 도메인 모델 구성
  - 트랙 정규화 좌표 -> XR 월드 좌표 변환 규칙 구현
  - 보간 정책(점프 방지) 적용
- 완료 기준:
  - 차량 위치가 트랙 범위 밖으로 벗어나지 않음
  - 업데이트 지연 시 시각적 끊김 완화 확인

## Phase 4. 트랙 에셋 제작/적용 (2~3일)
- 작업:
  - Blender 기반 모나코 트랙 베이스 메시 제작
  - 저폴리 최적화 + 기본 텍스처 적용
  - `GLB` 익스포트 및 XR 씬 로드 검증
  - 트랙 기준점/방향 정렬(좌표계 일치)
- 완료 기준:
  - 1m 기준 스케일 정확도 확인
  - 차량 마커가 트랙 선형을 자연스럽게 추종

## Phase 5. Presentation/XR 화면 구현 (2~3일)
- 작업:
  - ViewModel + UiState 구성
  - 차량 마커(팀 컬러 원형) 및 라벨 렌더링
  - 정보 패널(세션/상위권/날씨) 연결
  - 사용자 상호작용(시점 이동, 정보 토글) 적용
- 완료 기준:
  - 실시간 화면에서 주요 정보 식별 가능
  - 20~22대 동시 렌더 시 프레임 저하 허용 범위 내

## Phase 6. 안정화/테스트 (1.5~2일)
- 작업:
  - 계층별 테스트(Domain, Data, Presentation) 수행
  - 네트워크 변동/데이터 누락 시나리오 점검
  - 성능 프로파일링 및 최적화(업데이트 배치, 렌더 비용 절감)
- 완료 기준:
  - 주요 유스케이스 회귀 테스트 통과
  - 장시간 실행 안정성 확보

## API 적용 상세 매트릭스
- 세션 식별:
  - `meetings` + `sessions`
- 참가자 메타:
  - `drivers`
- 위치:
  - `location` (주)
- 속도:
  - `car_data` (주)
- 순위/격차:
  - `position` + `intervals` (보강)
- 환경 정보:
  - `weather`

## 리스크 및 대응
- OpenF1 실시간 접근 제약/요금 이슈:
  - 대응: 기록 데이터 기반 데모 모드 준비
- 위치 데이터 누락/불규칙:
  - 대응: 보간/캐시/유효시간 정책 적용
- XR 성능 병목:
  - 대응: 마커 단순화, 텍스처 압축, 업데이트 주기 튜닝

## 완료 정의(Definition of Done)
- 모나코 트랙 XR 표시(1m 스케일) 완료
- 차량 20~22대의 위치/속도 실시간 반영 완료
- Hilt 기반 3계층 구조에서 데이터 흐름 검증 완료
- MVP 문서 항목별 수용 기준 충족 및 체크리스트 완료
